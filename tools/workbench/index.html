Engine: checking…

The emulation engine is not running on this computer

An older engine is running on port that answers status calls but has no console page. Stop it (kill $(lsof -t -nP -iTCP: -sTCP:LISTEN)) and start the current one with the command below.

The engine drives the mouse and keyboard of the machine it runs on, so it always runs locally and this page only talks to it at 127.0.0.1:4320.

Start it from a terminal in the repo:

cd tools/emulation-engine && ./run.sh --no-open (macOS, Linux)

cd tools\emulation-engine ; .\run.ps1 -NoOpen (Windows)

First time on this computer: run ./install.sh (or .\install.ps1 on Windows) once before that. The README in that folder explains the Accessibility permission macOS will ask for.
