The emulation engine is not running on this Mac

The engine drives the mouse and keyboard of the machine it runs on, so it always runs locally and this page only talks to it at 127.0.0.1:4320.

Start it from a terminal in the repo:

cd tools/emulation-engine && ./run.sh --no-open

First time on this Mac: run ./install.sh once before that. The README in that folder explains the Accessibility permission macOS will ask for.
