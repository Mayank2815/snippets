Notes

This page is served by the engine itself, so it only works while ./run.sh (macOS, Linux) or .\run.ps1 (Windows) is running on this computer. Once started, the engine moves the pointer and presses navigation keys in whatever window is in front. Press Stop here, or Ctrl-C in the terminal, to end it. If nothing moves after Start on a Mac, allow your terminal app under System Settings → Privacy & Security → Accessibility; on Linux the engine needs an X11 session, not Wayland.

It keeps its own activity inside a measured band. A tracker scores ten minutes as 60 blocks of ten seconds, counting a block as active if anything happened in it; the engine gives each window a random share of those blocks, never goes above 65% of them, spreads the share across the whole window, and counts your typing against the same share. It stops on its own after a few hours, and it pauses completely while you are using the computer. Clicking is off unless you start it with ENGINE_ALLOW_CLICK=1.
